# FlowFix Plumbing Landing Page - PRD

## Original Problem Statement
Create a modern, high-converting landing page for a professional plumbing company (FlowFix Plumbing) in Brussels, Belgium with:
- Deep blue (#0A2540), white, and teal (#2EC4B6) color palette
- 9 sections: Hero, Services, Pricing, Why Choose Us, Testimonials, About, Contact, CTA Banner, Footer
- Brussels location with Euros (€) currency
- Demo contact form with Formspree integration ready

## User Personas
1. **Homeowners** - Need emergency plumbing repairs
2. **Property Managers** - Require regular maintenance services
3. **Businesses** - Seeking commercial plumbing solutions

## Core Requirements (Static)
- Responsive design (mobile, tablet, desktop)
- Fast-loading landing page
- Clear CTAs throughout
- Trust signals (Licensed, Insured, 5-Star Rated)
- 24/7 emergency service emphasis
- Transparent pricing display
- Contact form with service dropdown
